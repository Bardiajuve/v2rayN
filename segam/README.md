# وب‌سایت سه‌گام (فروشگاه عمده کفش)

سایت استاتیک کاملاً فارسی/RTL بدون نیاز به بیلد.

## اجرا
```
cd segam && python3 -m http.server 8000   # سپس http://localhost:8000
```
یا پوشه را روی هر هاست استاتیک آپلود کنید.

## ویرایش
- محصولات، حداقل سفارش و شماره‌ها: `js/data.js` (قیمت در سایت نمایش داده نمی‌شود؛ استعلام از طریق واتساپ/تلفن)
- عکس‌ها: `images/` طبق `IMAGE_PROMPTS.md`
- فونت: فایل `Vazirmatn.woff2` را در `fonts/` بگذارید (اختیاری؛ در غیر این صورت فونت سیستم)
- سفارش‌ها از طریق واتساپ مدیر فروش ارسال می‌شود (`whatsapp` در data.js).
